# Tiles do jogo

Coloque aqui os PNGs oficiais usados pelo cenário.

Ao abrir o app diretamente pelo arquivo `index.html`, o navegador não consegue copiar automaticamente um arquivo selecionado para esta pasta por motivos de segurança. O PNG continua salvo no mapa e no armazenamento local do navegador.

Para distribuir um conjunto fixo junto do jogo:

1. Coloque os PNGs nesta pasta.
2. Exporte o mapa em JSON.
3. Distribua o projeto com a pasta `tiles/` intacta.

Arquivos usados no mapa podem ser recolocados nesta pasta sem alterar o HTML ou o JavaScript.
